# Element Plus

Для интерактивных частей форм (Vue-компоненты [полей](../formfields/list.md): выбор,
загрузка медиа, редакторы, координаты и т.п.) используется библиотека
[Element Plus](https://element-plus.org/).

## Особенности

- По стилистике близка к Bootstrap 5, поэтому хорошо сочетается с текущей вёрсткой админки.
- **Сетка — 24 колонки** (а не 12, как в Bootstrap). Это важно учитывать при разметке
  внутри Vue-компонентов: значения `span`/ширин считаются из 24.

## Где применяется

Element Plus подключается на страницах редактирования DataType/PageType, где поля
рендерятся как Vue-инстансы (имя инстанса формируется хелпером `vue_instance_name()`).
Простые неинтерактивные поля выводятся обычной blade-вёрсткой на Bootstrap.

> Направление модернизации UI (в т.ч. возможный отказ от лишних JS-зависимостей и переход
> на единый UI-стек) — предмет отдельной исследовательской задачи рефакторинга.
