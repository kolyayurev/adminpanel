# Changelog

Все значимые изменения пакета `adminpanel` фиксируются здесь.
Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [SemVer](https://semver.org/lang/ru/) (стадия `0.x`).

## [Unreleased]

### Fixed
- Ошибки валидации в модальной форме показываются под полями, модалка остаётся открытой —
  раньше сабмит с ошибкой заканчивался общим тостом «Ошибка».
- Кнопка «Создать» во встроенной таблице не показывается, если политика запрещает создание.
- Запись, созданная из встроенной таблицы, по умолчанию принадлежит той записи, в чей блок
  её добавляют: поля подставляются из фильтра таблицы.

## [0.9.5] — 2026-07-22

### Added
- Компонент таблицы (`<x-adminpanel::datatable>`) можно встраивать в страницу записи с
  фильтром, залоченным на конкретную запись, и скрывать отдельные колонки. Несколько
  таблиц теперь можно размещать на одной странице без конфликтов.
- Формы создания и редактирования записи можно открывать в модальном окне прямо со
  страницы, без перехода на отдельную страницу.

## [0.9.4] — 2026-07-22

### Added
- Поле `EnumSelect` — работа с колонками, скастованными в enum, без ручной обвязки на
  стороне проекта.
- Поле `Json` для отображения json/jsonb-колонок в списке и на странице записи.
- `ModelRepository` — репозиторий для `DataType` без отдельного класса-наследника.

### Fixed
- `Select` с заполненным словарём опций ломал список и страницу записи (ошибка типа).
- Фильтры колонок в списке по числовым/логическим/датовым колонкам сравнивали через LIKE:
  падение на PostgreSQL и ложные совпадения на других СУБД. Теперь используют точное
  сравнение; множественный фильтр больше не расширяет выборку мимо остальных фильтров.

## [0.9.3] — 2026-07-10

### Fixed
- При неудачном входе в панель управления (неверный пароль или превышение лимита попыток)
  вместо локализованного сообщения могла показываться техническая строка (`auth.failed`).

## [0.9.2] — 2026-07-09

### Added
- Билдер меню сайдбара вынесен из вьюхи в PHP — точки расширения без переопределения вёрстки
  пакета: добавить свой пункт, унаследоваться от дефолтного меню, полностью подменить билдер.
  Страницы `CustomPage` теперь появляются в сайдбаре автоматически.

## [0.9.1] — 2026-07-09

### Fixed
- `ChartWidget` без явно заданных опций рисовал пустой график (без ошибок в консоли) —
  бэкенд отдавал `options` пустым JSON-массивом вместо объекта, и Chart.js молча его
  игнорировал.

## [0.9] — 2026-07-09

### Added
- Механизм виджетов и произвольных страниц из PHP-классов (`CustomPage`) — по аналогии с
  `PageType`/`DataType`, конструируются из PHP и переиспользуют существующий layout-движок
  (Row/Col/Card/Tabs). Универсальный async-эндпоинт подгрузки данных виджета без перезагрузки
  страницы.
- Графики «из коробки» на Chart.js: базовый класс `ChartWidget` (с полным доступом ко всем
  настройкам Chart.js — типы графиков, scales, plugins и т.д.) и готовый Vue-компонент.

### Fixed
- `AdminPanel::useModel()` теперь корректно применяется и к спискам (DataTable), а не только
  к формам создания/редактирования.

## [0.8] — 2026-07-09

### Added
- Guard и таблица пользователей админки настраиваются (`adminpanel.guard`,
  `adminpanel.users_table`) — админку можно подключить отдельным контуром, не занимая
  основную таблицу `users`. По умолчанию поведение прежнее.

### Changed
- `adminpanel:install` не трогает модель пользователей хоста, если админка настроена
  отдельным контуром (кастомный guard/таблица) — раньше команда вслепую правила
  `app/Models/User.php`.

## [0.7] — 2026-07-09

Модернизация фронтенда админки под Laravel 13 / PHP 8.4.

### Changed
- Сборка ассетов переведена на Vite.
- Интерфейс переведён на Vue 3 + Element Plus (нотификации, формы, таблицы, загрузка медиа).
- Меню — боковой сворачиваемый sidebar.
- Ссылки на ассеты версионируются: после обновления админки браузер сам подхватывает
  свежие стили и скрипты, без ручного сброса кэша.

### Removed
- Устаревшие фронтенд-зависимости: select2, datatables.net, sweetalert2, toastr, dropzone,
  bootstrap-fileinput, moment.

## [0.6]

- Исходная версия пакета.
